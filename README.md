# godot_tutorial

All assets and code were borrowed from this tutorial: https://www.youtube.com/watch?v=GwCiGixlqiU .
This project took about 5 hours to complete on and off over the course of a week.

# update 1
The game now enables the player to move using both the arrow keys and WASD.  This update took a couple minutes to implement.

# update 2
The game over screen is darker and features red text to come off as more detrimental.  This update took a couple minutes to implement.

# update 3
More slimes spawn gradually over time.  This update took about 10 minutes to implement.

# update 4 - secondary loop additions
1.) I added a points system via collectable coins scattered across the map.  The coin sprite is made by me and the godot scripts and logic are from this tutorial: https://www.youtube.com/watch?v=1YqZcpzolOA

2.) Collecting enough coins will increase the payer's speed.  Once enough coins are collected, they will be "spent" buying the speed boost, resetting your coin counter to zero.

3.) If you survive 45 seconds, a "you win" screen appears to congratulate you!
